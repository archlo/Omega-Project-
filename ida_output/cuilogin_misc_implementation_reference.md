# CUISoftKeyboard / CUICharacterSaleDlg / CUINewCharAvatarSelect / CUINewCharJobSelect — Implementation Reference

## CUISoftKeyboard
- On-screen keyboard for PIN entry
- Used during PIN login step
- Simple grid of character buttons
- Sends character input to PIN edit field

## CUICharacterSaleDlg
- Character sale/delete confirmation dialog
- Inherits CDialog (modal)
- Shows character info + confirmation
- Has name input for deletion confirmation

## CUINewCharAvatarSelect
- New character avatar selection (part of character creation)
- Select hair/face/color for new character
- Avatar preview display
- Color palette selection
- Job selection (if applicable)

## CUINewCharJobSelect
- New character job selection (part of character creation)
- Select job class for new character
- Shows available job classes
- Job description display
